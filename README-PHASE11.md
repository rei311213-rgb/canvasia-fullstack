# Canvasia Phase 11 — Professional Workspace & Productivity

Phase 11 builds on the Phase 10 professional editor with productivity controls for faster real-world design work.

## New features
- Toggleable 20px design grid.
- Toggleable center snap for positioning.
- Lock/unlock selected elements to prevent accidental editing.
- Copy/paste selected objects with keyboard shortcuts.
- Improved deletion behavior for locked elements.
- Locked elements display a non-editable cursor state.
- Keyboard shortcut help dialog.
- Existing undo/redo, grouping, alignment, rotation, resize, layers, templates, assets, sharing, autosave, PNG and PDF export retained.

## Shortcuts
- Ctrl/Cmd + C — Copy
- Ctrl/Cmd + V — Paste
- Ctrl/Cmd + D — Duplicate
- Ctrl/Cmd + G — Group
- Ctrl/Cmd + Shift + G — Ungroup
- Ctrl/Cmd + Z — Undo
- Ctrl/Cmd + Y — Redo
- Arrow keys — Move 1px
- Shift + Arrow — Move 10px
- Delete/Backspace — Delete
