# Canvasia Fullstack — Phase 10

## Professional Canva-style Editor

Phase 10 builds on Phase 9 and adds a richer professional design workflow while retaining the existing full-stack project, templates, assets, sharing, versions and exports.

### New editor capabilities
- Rich text formatting: font family, weight, size, alignment, underline, line spacing and letter spacing.
- Text and element shadows.
- Gradient fills with configurable secondary color.
- Page background color control.
- Group / ungroup selected elements.
- Duplicate selected elements and `Ctrl/Cmd+D` shortcut.
- Keyboard nudging with arrow keys; Shift+Arrow moves by 10px.
- Zoom control from 50% to 150%.
- Improved rotation and resize handles.
- Professional quick actions and layer ordering.
- Existing multi-select, snapping, alignment, undo/redo, autosave, version history, assets, templates, sharing and PNG/JPG/PDF export remain available.

## Keyboard shortcuts
- `Ctrl/Cmd + Z` Undo
- `Ctrl/Cmd + Shift + Z` Redo
- `Ctrl/Cmd + Y` Redo
- `Ctrl/Cmd + D` Duplicate
- `Ctrl/Cmd + G` Group
- `Ctrl/Cmd + Shift + G` Ungroup
- `Delete` / `Backspace` Delete
- Arrow keys Nudge
- `Shift + Arrow` Nudge by 10px

## Run
```bash
npm install
npm run db:push
npm run dev
```
